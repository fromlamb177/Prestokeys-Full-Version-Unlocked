<a id="main-features"></a>

### Core Functionality
- **Five Knowledge Levels** — PrestoKeys offers five levels of difficulty, allowing users to start from scratch or enhance their existing skills.
- **Two Input Methods** — Users can choose between different ways to input notes, catering to various learning preferences.
- **Different Types of Notation** — The program supports multiple musical notations, providing flexibility for different learning styles.
- **Metronome Feature** — A built-in metronome helps users maintain rhythm and timing during practice sessions.
- **Visual Aids** — Notes appear visually on the stave, guiding users on when to play each note as it passes a designated line.
